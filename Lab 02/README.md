# Lab 02 - Image Representation and Basic Operations

This lab covers how digital images are loaded, represented, displayed, cropped, resized, and analyzed.

## Topics

- Loading images with OpenCV
- RGB, BGR, and grayscale representations
- Inspecting pixels and channel ranges
- Separating color channels
- RGB-to-HEX conversion
- Cropping and resizing
- Grayscale histograms
- 8-bit and lower bit-depth quantization

| `lab02.ipynb` | Main notebook |
